## Commands to Run

```bash
# Backend
cd backend
py manage.py migrate
py manage.py seed
py manage.py runserver 0.0.0.0:8000

# Admin Portal
cd admin_portal
npm install
npm run dev

# Mobile App
cd mobile_app
npm install
npx expo start --clear
```
